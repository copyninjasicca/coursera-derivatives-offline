Model and validation

C = S·exp(−qT)·N(d₁) − K·exp(−rT)·N(d₂). P = K·exp(−rT)·N(−d₂) − S·exp(−qT)·N(−d₁).

d₁ = [ln(S/K) + (r−q+σ²/2)T] / (σ√T), d₂ = d₁−σ√T.

Terminal & touching probabilities

Continuous-monitoring geometric Brownian motion. Set two target prices and explore the chance of ending in a region or reaching a target at any time.

The risk-neutral option uses rate − yield − volatility²/2. Zero log drift uses μ=0 and does not use the entered rate/yield for path drift. It matches marginal probabilities in one saved original sample; vendor semantics remain unproven. Neither mode is an empirical forecast.
