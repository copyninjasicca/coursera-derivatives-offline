Stock Monitor

The Stock Monitor, powered by iVolatility, allows you to monitor key advanced metrics on stocks and indexes, including option volume, 30-day implied volatility (IVX), 20-day historical volatility (HV) and more. Users can also create and save personalized lists for easy reference each time you log in. Note that all data for US stocks, options, dividends and interest rates are provided with a 20-minute delay.
