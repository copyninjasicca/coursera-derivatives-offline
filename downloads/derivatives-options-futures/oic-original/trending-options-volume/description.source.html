Trending Options Volume

Trending Options Volume, powered by iVolatility, displays the top twenty stocks, indexes and ETFs which have the most traded options volume during the current market session. The table conveniently groups stock, ETF and index options into a single list, providing a snapshot of what's moving, call and put volumes and implied volatility metrics. Note that all data is provided with a 20-minute delay.
